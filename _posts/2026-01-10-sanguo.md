上次回国，买了三国演义[^1]。其缘由大概在于参观了成都的武侯祠，被其中的一些故事吸引，同时也感觉到自己对这段历史[^2]缺乏应有的了解。

于是这个周末，我打算在AI的帮助下，两天内看完三国演义，当然只是取其精华，忽略细节。

所以的讨论，可以参见[这里](https://chat.deepseek.com/share/fquw4k6q9ru0zhwkte)。总结如下：

### **一、以朝代（魏、蜀、吴）为主线的关键事件**

| 阵营 | 关键事件 | 说明 | 对应章回（约） |
| :--- | :--- | :--- | :--- |
| **蜀汉** | **桃园三结义** | 刘备、关羽、张飞创业起点。 | 第1回 |
| | **三顾茅庐** | 诸葛亮出山，提出《隆中对》。 | 第37-38回 |
| | **赤壁之战** | 孙刘联军破曹，奠定三分天下。 | 第43-50回 |
| | **进位汉中王** | 刘备势力达到顶峰。 | 第73回 |
| | **关羽失荆州** | 关羽北伐被东吴偷袭，败走麦城被杀。 | 第73-77回 |
| | **夷陵之战** | 刘备为关羽复仇，惨败于陆逊。 | 第81-84回 |
| | **白帝城托孤** | 刘备病逝，托孤于诸葛亮。 | 第85回 |
| | **诸葛亮北伐** | 诸葛亮为兴复汉室，多次出兵伐魏。 | 自第91回起 |
| | **诸葛亮病逝五丈原** | 北伐未成，巨星陨落。 | 第103-104回 |
| | **姜维北伐** | 继承诸葛亮遗志，九伐中原。 | 第107回后多次 |
| | **刘禅投降，蜀汉灭亡** | 邓艾偷渡阴平，后主出降。 | 第118回 |
| **曹魏** | **曹操刺董卓、发矫诏** | 曹操登上历史舞台。 | 第4-5回 |
| | **挟天子以令诸侯** | 迎汉献帝于许都，掌握政治主动权。 | 第14回 |

| | **司马昭弑君** | 司马昭杀皇帝曹髦，“司马昭之心”典故。 | 第114回 |
| | **司马炎篡魏** | 司马炎迫魏元帝禅让，建立晋朝。 | 第119回 |
| **东吴** | **孙策定江东** | “小霸王”打下基业。 | 第15、29回 |
| | **孙权继位** | 孙策遇刺，孙权掌权。 | 第29、38回 |
| | **赤壁之战** | 联刘抗曹，保住江东并扩张。 | 第43-50回 |
| | **偷袭荆州** | 背盟袭取荆州，擒杀关羽。 | 第75-77回 |
| | **夷陵之战** | 陆逊大败刘备，巩固荆州。 | 第81-84回 |
| | **孙权称帝** | 孙权正式称帝，三国名号俱全。 | 第108回 |
| | **孙皓暴政亡国** | 末帝孙皓投降，东吴灭亡。 | 第120回 |
